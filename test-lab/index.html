What this is

A hand-built static page: one HTML file, one stylesheet, one script. No build step, no framework, no tracking. The particle field is a canvas running a tiny simulation; everything else is the DOM.

  • Real, working interactions — nothing faked
  • Responsive down to a 360px phone
  • Accessible labels and keyboard support
  • No external dependencies except the fonts
