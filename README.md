# Lumen — Business Landing Page

একটা সম্পূর্ণ, responsive বিজনেস ল্যান্ডিং পেজ।
Light / clean থিম, English কনটেন্ট, vanilla HTML + CSS + JS — কোনো ফ্রেমওয়ার্ক বা বিল্ড স্টেপ নেই।

---

## চালু করা

কোনো ইনস্টল লাগবে না। শুধু ফোল্ডারটা ওপেন করেই `index.html` ডাবল-ক্লিক করলেই সাইট চলবে।

লাইভ সার্ভার চাইলে:

```bash
# Python
python3 -m http.server 8080

# অথবা Node
npx serve .
```

তারপর ব্রাউজারে `http://localhost:8080`

---

## ফাইল

| ফাইল | কী আছে |
| --- | --- |
| `index.html` | সব কনটেন্ট আর সেকশন |
| `styles.css` | পুরো ডিজাইন সিস্টেম |
| `script.js` | ৯টা ইন্টারঅ্যাকশন |

কোনো বিল্ড, npm install বা bundler লাগে না — সরাসরি ব্রাউজারে চলে।

## নিজের বিজনেসে বদলানো

সবচেয়ে সহজ কাজগুলো:

**ব্র্যান্ড বদলাতে** — `index.html`-এ `Lumen` লেখা সব জায়গা খুঁজে বদলাও।
লোগো SVG খুঁজবে `class="brand__mark"`, ফেভিকনের জন্য `<link rel="icon">` লাইনটা দেখো।

**রঙ বদলাতে** — `styles.css`-এর শুরুতে `:root` ব্লক। সবাই এখান থেকে আসে:

```css
:root{
  --brand:#4f46e5;   /* মূল অ্যাকসেন্ট */
  --brand-dark:#4338ca;
  --sky:#0ea5e9;
  --ink:#0d1220;     /* টেক্সট */
  --muted:#6b7688;   /* সেকেন্ডারি টেক্সট */
  --line:#e6e9f0;    /* বর্ডার */
}
```

**টেক্সট বদলাতে** — `index.html` সরাসরি এডিট করো। সব কপি HTML-তেই আছে,
কোনো টেমপ্লেট বা JSON দরকার নেই।

**টেকস্ট ছবি বসাতে** — `.hero__visual`-এর ভেতরের ড্যাশবোর্ড মক-আপটি HTML/CSS দিয়ে বানানো।
নিজের প্রোডাক্টের স্ক্রিনশট বসাতে চাইলে পুরো `<div class="mock">…</div>` ব্লকটা
`<img src="hero.png" alt="…">` দিয়ে রিপ্লেস করো।

**ফর্ম কাজ করানো** — ফর্মগুলো এখন শুধু ফ্রন্ট-এন্ডে ভ্যালিডেট করে। আসল সাবমিট পাঠাতে
`script.js`-এ `wireForm()` ফাংশনে `fetch()` যোগ করো:

```js
fetch('/api/trial', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: value })
});
```

## ফিচার

- স্টিকি ন্যাভ + মোবাইল হ্যামবার্গার মেনু
- স্ক্রল করলে সেকশন ফেড-ইন অ্যানিমেশন (IntersectionObserver)
- স্ক্রল-স্পাই — ন্যাভে কোন সেকশনে আছো তা হাইলাইট হয়
- অ্যানিমেটেড কাউন্টার (সংখ্যা গণনা)
- মাসিক/বার্ষিক প্রাইসিং টগল
- FAQ অ্যাকর্ডিয়ন (একসাথে একটাই খোলা)
- ইমেইল ভ্যালিডেশন সহ দুটো ফর্ম
- মোবাইল, ট্যাবলেট, ডেস্কটপ — সব সাইজে responsive
- `prefers-reduced-motion` সাপোর্ট (অ্যানিমেশন বন্ধ হয়)
- কীবোর্ড নেভিগেশন + skip-link অ্যাক্সেসিবিলিটি
